# 🚗 Introduction to Self-Driving Cars

This repository contains my completed assignments and project work from the **Introduction to Self-Driving Cars** course. It includes implementations using the **CARLA simulator**, vehicle control, waypoint navigation, and controller development.

I created this repository as a **learning and reference resource** for students who may find the course assignments, CARLA setup, or controller implementation difficult.

## 📚 About the Course

The course introduces the fundamental concepts used in autonomous vehicles and provides practical experience with vehicle control and simulation.

The main project involves controlling a simulated vehicle to follow a predefined race track by navigating through waypoints and maintaining desired speeds.

## 🛠️ Topics Covered

* Autonomous vehicle fundamentals
* CARLA Simulator
* Vehicle control
* Waypoint navigation
* Longitudinal control
* Lateral control
* Steering control
* Speed control
* Python programming
* Controller implementation
* Simulation and testing

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

### 2. Install the Required Software

You may need:

* Python
* CARLA Simulator
* Required Python packages
* Course-provided project files

Make sure the CARLA version matches the version required by the project.

### 3. Set Up CARLA

Install and launch the CARLA simulator before running the controller.

The controller communicates with the CARLA simulator and controls the vehicle during the simulation.

### 4. Run the Project

Navigate to the project directory:

```bash
cd Course1FinalProject
```

Then run the appropriate Python controller file:

```bash
python controller.py
```

> The exact filename may be different depending on the project files included in this repository.

## 🎯 Project Objective

The main objective of the project is to develop a controller that enables a vehicle to:

1. Follow predefined waypoints.
2. Maintain the desired vehicle speed.
3. Control steering according to the track.
4. Navigate the race track successfully.
5. Combine longitudinal and lateral control.

## 🧠 Learning Purpose

This repository is intended to help students understand the implementation and workflow of the course projects.

I recommend using the solutions as a **reference for learning and debugging** rather than simply copying the code. Understanding how the controller works will make it much easier to modify, troubleshoot, and improve it.
